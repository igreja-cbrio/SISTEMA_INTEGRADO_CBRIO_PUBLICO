Arquitetura do sistema

Mapa técnico da edição pública. Documentação operacional, pessoas e auditorias internas permanecem no repositório privado.

Interface

React e TypeScript apresentam os módulos e consultam a API autenticada.

src/ → api/

API e serviços

O backend aplica as permissões, valida entradas e executa os serviços de cada módulo.

backend/routes/ → backend/services/

Persistência

O banco é configurado por variáveis privadas. Dados de produção e histórico de importações não fazem parte desta edição.

PostgreSQL · Supabase
